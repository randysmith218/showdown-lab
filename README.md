# Showdown Lab — DK Classic builder (Main 12gs)

DraftKings NFL Classic lineup builder. No sign-in. No database.

## Deploy on Vercel (shareable link)

1. Open: https://vercel.com/new/clone?repository-url=https://github.com/randysmith218/showdown-lab
2. Import this repo.
3. Set environment variable **`VITE_AUTH_ENABLED`** = **`false`**
4. Framework: Other. Build: `npm run build`. Node 22.
5. Deploy. Send your friend the `*.vercel.app` URL.

## Local

```bash
npm install
npm run dev
```
